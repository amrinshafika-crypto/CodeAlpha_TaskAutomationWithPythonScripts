# Task Automation with Python Scripts 🗂️

A simple Python automation project that moves all `.jpg` files from a source folder to a destination folder automatically.

---

## 🚀 Features

- Automatically detects JPG files
- Moves files from one folder to another
- Creates destination folder if it does not exist
- Simple and beginner-friendly automation script

---

## 🛠️ Technologies Used

- Python
- os module
- shutil module
- File handling

---

## 📚 Concepts Used

- Loops
- Conditions
- File handling
- Folder operations
- Automation scripting
